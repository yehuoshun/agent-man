# 一天长什么样

这份不是教程，是一次真跑的记录：拿一个空目录当数据目录（`AGENT_MAN_HOME=tmp/doc-day`），
按某一天的实际顺序把命令敲一遍，输出原样贴在这儿。日期 2026-11-12，机器时区 Asia/Shanghai。

看它是为了回答一个问题：**模型从这些命令里拿到的，到底是"台词"还是"处境"？**

## 07:40 她说了一句梦话

```
$ agent-man log 早上她说梦到搬家，醒了还念叨 --at 07:40
2026-11-12T07:40:00+08:00 +14  早上她说梦到搬家，醒了还念叨
```

`+14` 是这条日记的预算代价——只是把账记给你看，不需要谁去关心它。

## 12:10 中午

```
$ agent-man log 中午她自己煮了面，说盐又放多了 --at 12:10
2026-11-12T12:10:00+08:00 +15  中午她自己煮了面，说盐又放多了
```

## 13:05 一件她惦记的事

`--weight 2` 是"这条重要，摘要里优先留"。零件不判断一条事重不重要，权重是人给的。

```
$ agent-man log 她说周五的体检报告该出来了 --weight 2 --at 13:05
2026-11-12T13:05:00+08:00 w2 +13  她说周五的体检报告该出来了
```

## 13:20 把散着的日记收成一句结论

长期层放的是**结论**，不是原文；原文永远留在日记里，`refs` 是回去的路。

```
$ agent-man remember 入秋先关窗再抱怨风 --topic 她怕冷 --refs 2026-11-11
2026-11-12-01  tier0  - 她怕冷：入秋先关窗再抱怨风
  出处: 2026-11-11
  结账: 清了 3 条日记
```

`结账` 意思是"这几条日记已经收进长期层了，下次 `digest` 不用再摊一遍欠账"。

## 13:25 给下一次的自己留一句

便条是给"未来的自己"的一句话，必须写清什么时候该说；递出去一次就烧掉，7 天不取作废。

```
$ agent-man leave 别急着问结果，先说今天辛苦了 --when 她提体检
留好了 2026-11-12-01：别急着问结果，先说今天辛苦了
  说的时候：她提体检
  留 7 天，到 2026-11-19 为止；递出一次就烧掉
```

## 13:30 日程

```
$ agent-man plan 她要做体检 --at "2026-11-12 09:30"
记下了 2026-11-12-p01：她要做体检
  2026-11-12 09:30（4 小时前）
```

## 13:35 该不该开口

调度器敲的就是这一条。它只回答"要不要说、说到什么"，不生成任何台词。

```
$ agent-man cue
这会儿 13:35。
你还没在这儿开过口。
之后攒了 3 条：
2026-11-12T07:40:00+08:00  [note]  早上她说梦到搬家，醒了还念叨
2026-11-12T12:10:00+08:00  [note]  中午她自己煮了面，说盐又放多了
2026-11-12T13:05:00+08:00 w2  [note]  她说周五的体检报告该出来了
想看全：digest --budget 300
还留了 1 张便条（看过就烧，不会再端一次）：
· 2026-11-12-01  别急着问结果，先说今天辛苦了
  说的时候：她提体检
今天的安排：
· 09:30  她要做体检（已经过点了）
· 15:00  她下午三点开会，别吵
```

`[note]` 是日记的 `kind`，`w2` 是权重——都是元数据，模型一眼扫过去就知道哪条要紧。
"已经过点了"是零件替模型算好的：不然它会把九点半的事说成还没到。

## 13:35 再敲一次：不打扰

同一个进程再来一次（真实场景里是半小时后），它自己判断这回没什么可说的：

```
$ agent-man cue
这会儿 13:35，不打扰：没有新东西；刚刚才开过口，不到 6 小时；今天还有 2 条安排
```

## 13:40 要看全的时候

`cue` 只给索引，`digest` 才把整段处境压进预算里。三层：长期层（记住的事）→ 钉住的（不会忘的）→ 最近的。

```
$ agent-man digest --budget 400
# 我记得的事
<!-- agent-man · 日记 3 条 / 长期 1 条 · 取 3+1 · 预算 400 · 条目 80 · 丢 0 · 截 0 · 2026-11-12T13:35:53+08:00 -->

## 记住的事
- 她怕冷：入秋先关窗再抱怨风

## 不会忘的
- 30 分钟前 · 她说周五的体检报告该出来了

## 最近
- 5 小时前 · 早上她说梦到搬家，醒了还念叨
- 1 小时前 · 中午她自己煮了面，说盐又放多了
```

`<!-- … -->` 那行是账单：几条日记、几条长期、预算多少、实际条目多少、丢了几条、截了几条。

## 13:45 外面什么样

```
$ agent-man place 上海
记下了：上海，上海市，中国
  31.22222, 121.45806（Asia/Shanghai）；以后看天就用这个坐标
$ agent-man sky
上海 13:35，阴，18.1℃
今天 13.3–18.2℃，雨 2.7mm，明天 14.5–21.4℃
第一次看天，先记下这个样子。
今天的安排：
· 09:30  她要做体检（已经过点了）
· 15:00  她下午三点开会，别吵
$ agent-man sky
上海 13:35，阴，18.1℃——和上次说的一样，不打扰；今天还有 2 条安排
```

第二次打天气源都没碰：半小时内用缓存，跨了日就只说"上次是几号"，超过一天当没有。

## 13:50 看账

```
$ agent-man trace
最近 1 次 digest（共 1 次）：
2026-11-12T13:35:53+08:00  预算 400 · 用 138 · 取 3 · 长期 1 · 丢 0 · 截 0
```

## 这一天里，零件做了哪些判断

- 每个命令都是**跑一次就退出**的进程：没有常驻、没有轮询、没有后台队列。钟在外面。
- 输出里没有一句"台词"：全是时间、事实、几条、几张、要不要开口。说不说、怎么说，是模型的事。
- 数字都是现成的：3 条日记、1 张便条、2 条安排。模型不用自己数，也就不会数错。
- 该守的都守住了：便条递过就烧、作废的只报一次、日记不重复念、"已经过点了"处处都标。
